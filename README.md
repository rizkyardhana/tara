# TARA

Workspace TARA terdiri dari dua aplikasi:

## Frontend Flutter

```bash
cd frontend
flutter pub get
flutter run
```

## Backend Node.js

Buka terminal kedua:

```bash
cd backend
pnpm install
pnpm run dev
```

Backend berjalan di `http://localhost:8000`.
Health check: `http://localhost:8000/api/health`

Jalankan frontend dan backend pada terminal terpisah.
