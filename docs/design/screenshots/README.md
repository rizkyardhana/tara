## Cara mengambil ulang
Dev server jalan di `http://localhost:3000`. Buka layar apa pun langsung lewat hash:

```
http://localhost:3000/#s=home          → buka layar Beranda
http://localhost:3000/#shot&s=tara-ai  → mode screenshot (tombol melayang disembunyikan)
```
